# Gradio App 1 — Basic Classification Demo

A minimal Gradio application demonstrating how to connect a Python function to an interactive web interface.

The user enters a class index (`0`, `1`, or `2`) and the app displays **Cat**, **Dog**, or **Person**. This is a rule-based demo; it does **not** run a trained model.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open the local URL shown in the terminal.
